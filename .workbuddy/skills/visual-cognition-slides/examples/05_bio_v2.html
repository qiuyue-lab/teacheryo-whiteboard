目标：看图认结构 → 对比差异 → 理解功能
为什么细胞是生命基本单位？
① 能独立完成生命活动
细胞可以独立：摄食 → 代谢 → 分裂 → 感应
低于细胞层次的单位（细胞器）不能独立存活
② 结构决定功能
每种细胞的形态直接对应其功能
红细胞圆盘形 → 堆叠传氧；神经细胞长突起 → 传导信号
③ 疾病发生在细胞层次
癌症 = 细胞分裂失控  |  感染 = 病原体侵入细胞
治疗 = 作用于细胞

🏛️
细胞核
= 市政厅（指挥中心）

⚡
线粒体
= 发电厂
有氧呼吸；产生ATP（能量货币）
☀️
叶绿体
= 太阳能电站（植物独有）
光合作用；光能→化学能；产O₂
🚧
细胞膜
= 海关/关卡
选择性通透；信号接收；细胞识别
🏗️
核糖体
= 蛋白质加工厂
合成蛋白质；mRNA翻译的场所
🏊
液泡
= 水库+仓库（植物独有）
储水·色素·废物；维持细胞膨压
